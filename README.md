# Карман — нативный проигрыватель iPhone

Это исходный проект iOS-приложения на SwiftUI, НЕ веб-сайт и НЕ готовый IPA.
Требуется iOS 16+. Сборка в Xcode и установка на устройстве пока не проверены:
среда подготовки проекта — Linux, без Apple SDK. При первом облачном запуске
может потребоваться исправить ошибки компиляции; логи сборки позволят это сделать.

## Реализовано в исходниках

- Импорт нескольких аудиофайлов через системное приложение «Файлы», включая iCloud.
- Копирование в Documents/Music приложения, хранение коллекции в JSON.
- Проигрывание локальных MP3/M4A и других поддерживаемых AVAudioPlayer форматов.
- Поиск, импорт целой папки с подпапками, фильтрация по папке, плейлисты.
- Интерфейс в духе Apple Music: красный акцент, системная светлая/тёмная тема.
- Вкладки «Медиатека», «Папки», «Плейлисты», «Поиск», мини-плеер и большой экран.
- Без обязательного раздела «Избранное» и без лимита на число песен.
- Чтение названия, исполнителя, альбома и встроенных обложек при импорте.
- Просмотр очереди, «Следующей» и «В конец очереди». «Следующей» выключает перемешивание.
- Перемотка, предыдущая/следующая песня, перемешивание, три режима повтора.
- Категория AVAudioSession.playback и фоновый режим audio.
- Название песни и управление на экране блокировки / с наушников.
- Пауза при отключении наушников, обработка телефонных прерываний.
- Системный регулятор громкости и выбор аудиомаршрута.
- Нет сервера, аналитики, рекламы и покупок.

Это базовая самостоятельная версия: пока нет эквалайзера,
синхронизации с облачными дисками, автоматического наблюдения за изменениями исходных папок и редактирования тегов.
Если тег названия отсутствует, используется имя файла. Плейлисты не меняют оригиналы песен.
У ранее импортированных песен обложки и теги появятся после повторного импорта.
Это самостоятельный плеер, а не полный аналог всех возможностей Evermusic.
Импорт большого файла из iCloud зависит от сети; дождись окончания импорта
перед выходом из приложения. Удаление приложения удаляет его коллекцию.

## Как получить IPA, имея только Windows

Потребуется аккаунт GitHub. Apple ID и сертификаты в GitHub не нужны:
облако создаёт неподписанный IPA, AltStore подписывает его при установке.

1. Распакуй архив.
2. Создай репозиторий GitHub и загрузи СОДЕРЖИМОЕ этой папки в корень.
   Важно загрузить также скрытую папку `.github/workflows`.
   Через Windows включи отображение скрытых элементов или используй GitHub Desktop.
3. Открой репозиторий → Actions → Build iPhone app → Run workflow.
4. После успешной сборки скачай artifact `Karman-iPhone` и распакуй ZIP.
   Внутри будет `Karman-unsigned.ipa`.
5. Установи AltStore Classic через AltServer на Windows по официальной инструкции:
   https://faq.altstore.io/altstore-classic/how-to-install-altstore-windows
6. Перенеси IPA на iPhone в «Файлы». В AltStore → My Apps → + выбери IPA.
7. После установки открой «Карман» → + → выбери музыку.

GitHub стандартные macOS-раннеры бесплатны для публичного репозитория;
в приватном расходуется включённая квота. Чтобы избежать расходов, не включай
платный перерасход / оставь нулевой бюджет. Workflow запускается только вручную,
не на каждое изменение. Артефакт удаляется через 3 дня — сохрани IPA у себя.

AltStore Classic с обычным бесплатным Apple ID требует обновления подписи
не реже одного раза в 7 дней. Для этого нужен запущенный AltServer на компьютере
и доступ к нему с iPhone (кабель или настроенная Wi-Fi-синхронизация).
Если подпись истекла, приложение перестанет открываться до её обновления.
Бесплатный лимит — три установленных через этот механизм приложения, включая
AltStore. Доступность и совместимость установки нужно проверить на твоей iOS.
Пароль Apple ID вводи только самостоятельно в локальном процессе AltStore;
не отправляй его в чат и не добавляй в исходники / GitHub.

## На Mac

Установи Xcode и XcodeGen (`brew install xcodegen`). Затем:

```sh
xcodegen generate
open Karman.xcodeproj
```

Для обычной установки из Xcode укажи свою Team, уникальный Bundle ID
и включи подпись в настройках проекта (исходный проект настроен для неподписанной CI-сборки).

## Что проверить на устройстве после сборки

1. Импорт двух MP3 из локальных «Файлов» и одного из iCloud.
2. Воспроизведение и переход к следующей песне при заблокированном экране.
3. Play/pause/next с экрана блокировки и наушников.
4. Сохранение коллекции / импортированных папок / плейлистов после перезапуска.
5. Пауза при отключении наушников, звонок и восстановление аудио.
6. Импорт папки с вложенной папкой, пропуск посторонних файлов.
7. Удаление песни: копия в оригинальной папке должна оставаться.
8. Обложки и теги MP3, поиск по исполнителю, альбомы, обе темы оформления.
9. Очередь: добавить следующую песню и в конец; проверить порядок переходов.
10. Мини-плеер должен оставаться доступен в папках, альбомах и плейлистах.

Официальные ссылки:
- https://faq.altstore.io/altstore-classic/your-altstore
- https://developer.apple.com/documentation/avfaudio/avaudiosession/category-swift.struct/playback
- https://docs.github.com/en/actions/reference/runners/github-hosted-runners

## Установка без AltStore

После получения IPA можно использовать Sideloadly на Windows:
https://sideloadly.io/
Он устанавливает приложение прямо на iPhone. AltStore на телефон не нужен.
С бесплатным Apple ID подпись также действует 7 дней и требует обновления.
Сборка IPA и подпись — отдельные шаги; ZIP с исходниками установить нельзя.
